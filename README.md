- # 2. PDF合并功能
### 2.1 功能介绍

将多个PDF发票文件合并到一个PDF文件中，支持灵活的排版方式：
- 支持多列网格布局（1-10列）
- 支持A4纸横向/纵向排版
- 🆕 所有PDF智能布局到一页A4纸上
- 🆕 自定义文件名前缀（前缀-1.pdf、前缀-2.pdf...）
- 预览第一批文件的实际合并效果
- 自动缩放适应A4纸张

### 2.2 详细操作步骤

**第一步：准备PDF文件**
1. 将需要合并的PDF发票文件放在同一个文件夹中
2. 确保PDF文件可以正常打开

**第二步：选择输入文件夹**
1. 打开软件，点击"📑 PDF合并"标签页
2. 点击"选择文件夹"按钮
3. 浏览并选择包含PDF文件的文件夹
4. 软件会自动扫描并显示找到的PDF文件数量
   - 示例：找到 50 个PDF文件

**第三步：设置合并参数**

**2.3.1 每次合并文件数**
- 默认值：10
- 含义：每10个PDF文件合并成1个PDF文件，所有PDF在一页A4纸上
- 示例：50个文件，设置为10，最终生成5个合并文件，每个文件1页A4纸
- 建议：
  - 打印用途：设置为4-9个（一张纸打印多个发票）
  - 归档用途：设置为10-20个（便于查看）
  - 注意：数量越多，单个PDF缩放越小

**2.3.2 每行几列**
- 默认值：1（垂直排列）
- 选项：1-10列
- 含义：
  - **1列**：每页1个发票，垂直排列（最清晰）
  - **2列**：每页2个发票，左右排列
  - **3列**：每页3个发票，三列排列
  - **4列**：每页4个发票，四列排列
  - 更多列同理...
- 建议：
  - 标准发票（A4大小）：建议1-2列
  - 小票据：可以设置3-4列

**2.3.3 纸张方向**
- **纵向（A4竖版）**：推荐，适合大部分发票
  - 尺寸：210mm × 297mm
  - 适用：标准发票、电子发票
- **横向（A4横版）**：适合宽型发票
  - 尺寸：297mm × 210mm
  - 适用：宽屏幕发票、横向表格

**🆕 2.3.4 文件名前缀**
- 默认值：合并发票
- 自定义前缀，生成的文件命名为：前缀-1.pdf、前缀-2.pdf、前缀-3.pdf...
- 示例：
  - 前缀设为"2024年1月发票"，生成文件：2024年1月发票-1.pdf, 2024年1月发票-2.pdf...
  - 前缀设为"项目A"，生成文件：项目A-1.pdf, 项目A-2.pdf...

**第四步：预览效果（可选但推荐）**
1. 点击绿色的"预览效果"按钮
2. 🆕 查看第一批PDF（根据"每次合并文件数"）在A4纸上的实际排版效果
3. 预览窗口显示：
   - A4纸张边框
   - PDF缩略图
   - 网格布局效果
   - 纸张方向标识
4. 如果效果不满意，关闭预览窗口，调整参数后重新预览
5. 确认效果满意后，关闭预览窗口

**第五步：选择输出文件夹**
1. 点击"选择输出文件夹"按钮
2. 选择合并后PDF文件的保存位置
3. **建议不要选择原文件夹**，避免文件混淆

**第六步：开始合并**
1. 点击"开始合并"按钮
2. 软件开始处理，进度条显示当前进度
3. 日志区域显示处理信息
4. 合并完成后会弹出提示窗口

**第七步：查看结果**
1. 打开输出文件夹
2. 🆕 查看生成的合并文件（文件名：前缀-1.pdf, 前缀-2.pdf...）
3. 打开PDF文件确认合并效果

### 2.3 使用示例

**示例1：打印用途 - 一张纸打印多个发票**
```
文件数量：50个发票
每次合并文件数：9
每行几列：3
纸张方向：纵向
结果：生成6个PDF文件，每个文件包含9个发票，每页3列×3行排列
用途：打印在A4纸上，节省纸张
```

**示例2：归档用途 - 按项目合并**
```
文件数量：100个发票
每次合并文件数：20
每行几列：1
纸张方向：纵向
结果：生成5个PDF文件，每个文件20个发票，垂直排列
用途：按项目分类归档
```

**示例3：账目对比 - 横向排列**
```
文件数量：40个发票
每次合并文件数：10
每行几列：2
纸张方向：横向
结果：生成4个PDF文件，每个文件10个发票，每页左右2列
用途：方便横向对比查看
```

### 2.4 注意事项

⚠️ **重要提示：**
- 合并前建议先备份原文件
- 预览功能只显示前9个PDF，实际会处理所有文件
- 文件数量较多时，合并可能需要几分钟
- 确保输出文件夹有足够的磁盘空间
- 合并过程中不要关闭软件

## 3. 信息提取功能

### 3.1 功能介绍

从PDF发票中自动提取完整信息并导出到Excel表格，支持：
- 🆕 全电发票：提取13个基础字段 + 8个明细行字段
- 🆕 火车票：提取15个字段（发票信息+车票信息）
- 可选插入PDF高清图片到Excel
- 自动识别发票类型
- 🆕 自动检测并提示重复发票
- 100%准确率提取核心字段

### 3.2 详细操作步骤

**🆕 第一步：选择文档类型**
1. 点击"📊 信息提取"标签页
2. 选择文档类型：
   - **全电发票**：处理电子普通发票、增值税专用发票等
   - **火车票**：处理火车票电子客票

**第二步：选择输入文件夹**
1. 点击"选择文件夹"按钮
2. 选择包含PDF发票的文件夹
3. 软件自动扫描并显示找到的PDF文件数量

**第三步：设置提取选项**

**3.3.1 是否提取明细行（仅全电发票）**
- **勾选"提取明细行"**：
  - 提取每个发票的商品明细
  - Excel中每个明细行单独占一行
  - 适合需要分析明细数据的场景
  - 示例：
    ```
    发票号码 | 开票日期 | 项目名称 | 数量 | 单价 | 金额
    --------|---------|---------|------|------|------
    2024... | 2024-01 | 橡胶制品 | 120  | 5.87 | 704.07
    2024... | 2024-01 | 设计服务 | 1    | 73.92| 73.92
    ```

- **不勾选"提取明细行"**：
  - 只提取发票汇总信息
  - Excel中每个发票占一行
  - 适合快速查看发票汇总的场景
  - 示例：
    ```
    发票号码 | 开票日期 | 销售方名称 | 价税合计
    --------|---------|----------|----------
    2024... | 2024-01 | XX公司   | 795.60
    ```

**3.2.2 是否插入PDF图片**
- **勾选"插入PDF图片到Excel"**：
  - 在Excel中插入每个发票的高清图片
  - 图片保留原始清晰度，可放大查看
  - 便于核对发票原件
  - **注意**：文件较多时处理速度较慢，生成的Excel文件较大

- **不勾选**：
  - 只导出文字信息
  - 处理速度快，文件小
  - 适合只需要数据的场景

**第四步：选择Excel保存位置**
1. 点击"选择保存位置"按钮
2. 输入Excel文件名（如：发票信息汇总.xlsx）
3. 选择保存位置

**第五步：开始提取**
1. 点击"开始提取"按钮
2. 软件开始处理：
   - 使用坐标解析器提取信息（极速，<0.2秒/张）
   - 进度条显示当前进度
   - 日志显示处理详情
3. 提取完成后显示成功数量
4. 🆕 **自动检测重复发票**：日志区域显示重复发票列表

**第六步：导出到Excel**
1. 提取完成后，"导出到Excel"按钮变为可用
2. 点击"导出到Excel"按钮
3. 软件开始导出：
   - 生成Excel文件
   - 格式化表格（边框、颜色、冻结首行）
   - 如勾选了插入图片，会逐个插入高清图片
4. 导出完成后弹出提示

**第七步：查看Excel**
1. 打开导出的Excel文件
2. 检查数据是否完整
3. 如有图片，可点击图片查看原始发票

## 4. 批量去重功能

### 4.1 功能介绍

自动识别重复的发票文件，帮助您清理重复下载或重命名的发票，支持两种去重模式：
- 🆕 按发票号码去重（支持全电发票和火车票）
- 按文件内容去重（最准确）

### 4.2 详细操作步骤

**第一步：选择去重模式**

**4.2.1 按发票号码去重（推荐）**
- 原理：提取发票号码进行比对
- 速度：快（<0.2秒/张）
- 准确率：高
- 🆕 支持全电发票和火车票
- 适用场景：
  - 文件被重命名
  - 同一发票不同来源
  - 确认是否重复开票
- 示例：
  ```
  2024年发票_A公司.pdf     （发票号：12345678） ← 保留
  报销单_项目一.pdf         （发票号：12345678） ← 重复（号码相同）
  2024年发票_B公司.pdf     （发票号：87654321） ← 保留（号码不同）
  ```

**4.2.2 按内容去重**
- 原理：计算文件内容MD5哈希值
- 速度：较慢（需读取整个文件）
- 准确率：最高（100%准确）
- 适用场景：
  - 需要绝对准确
  - 文件可能被修改metadata
  - 确保没有任何重复
- 示例：
  ```
  发票A.pdf      （MD5: abc123...） ← 保留
  发票B.pdf      （MD5: abc123...） ← 重复（内容完全相同）
  发票C.pdf      （MD5: def456...） ← 保留（内容不同）
  ```

**🆕 第二步：选择文档类型（按发票号码去重时）**
- **全电发票**：处理电子普通发票、增值税专用发票等
- **火车票**：处理火车票电子客票

**第三步：选择要去重的文件夹**
1. 点击"选择文件夹"按钮
2. 选择包含PDF发票的文件夹
3. 软件会扫描并显示文件数量

**第四步：开始去重**
1. 点击"开始去重"按钮
2. 软件开始分析：
   - 按发票号码：约0.2秒/张
   - 按内容：约1-2秒/张
3. 分析完成后显示结果：
   - 唯一文件数：XX个
   - 重复文件数：XX个

**第五步：查看去重结果**
- 日志区域显示详细信息
- 重复文件列表（如有）
- 检查是否有误判

**第六步：移除重复文件（可选）**
1. 确认去重结果正确
2. 选择处理方式：
   - 勾选"删除重复文件"（谨慎使用，不可恢复）
   - 或勾选"将重复文件移动到指定文件夹"（推荐）
3. 执行删除或移动操作

### 4.3 使用示例

**示例1：清理重复下载的发票**
```
场景：从邮箱多次下载，有重复文件
模式：按文件名去重
结果：
  找到100个文件
  唯一文件：80个
  重复文件：20个（重复下载）
操作：删除20个重复文件
```

**示例2：检查是否重复开票**
```
场景：怀疑供应商重复开票
模式：按发票号码去重
结果：
  找到50个文件
  唯一发票号：48个
  重复发票号：2个
操作：不删除，人工核查这2个发票
```

**示例3：合并多个文件夹后去重**
```
场景：整理多个项目的发票到一个文件夹
模式：按内容去重
结果：
  找到300个文件
  唯一文件：250个
  重复文件：50个（不同项目中的重复）
操作：删除50个重复文件
```

### 4.4 注意事项

⚠️ **重要提示：**
- **删除前一定要备份原文件！**
- 删除操作会将文件移到回收站，但仍建议提前备份
- 按发票号码去重时，如果PDF无法提取号码，会跳过该文件
- 按内容去重最准确但速度较慢，大批量时建议先用其他模式
- 去重结果建议人工复核后再删除

**删除前检查清单：**
- [ ] 已备份原文件
- [ ] 确认去重模式选择正确
- [ ] 查看了去重结果日志
- [ ] 重复文件数量合理
- [ ] 确认要删除的文件确实是重复的

## 5. 批量重命名功能

### 5.1 功能介绍

根据发票内容自动重命名文件，让文件名更有意义、更易管理，支持：
- 🆕 全电发票和火车票两种文档类型
- 🆕 复选框多选发票字段组合命名
- 自定义分隔符
- 自定义前缀和后缀
- 实时预览重命名效果
- 支持原地重命名或复制到新文件夹
- 🆕 完成后自动检测并提示重复发票

### 5.2 详细操作步骤

**🆕 第一步：选择文档类型**
1. 点击"✏️ 批量重命名"标签页
2. 选择文档类型：
   - **全电发票**：处理电子普通发票、增值税专用发票等
   - **火车票**：处理火车票电子客票

**第二步：选择输入文件夹**
1. 点击"选择文件夹"按钮
2. 选择包含PDF发票的文件夹
3. 软件显示找到的文件数量

**第三步：提取发票信息**
1. 点击"1. 提取发票信息"按钮
2. 软件开始提取所有PDF的发票信息
3. 🆕 提取完成后，自动检测并显示重复发票
4. 可以进行下一步设置

**🆕 第四步：选择重命名字段（复选框多选）**
- 在字段列表中勾选用于命名的字段（可多选）

**全电发票可用字段：**
- 发票号码、开票日期、购买方名称、购买方税号
- 销售方名称、销售方税号、合计金额、合计税额
- 价税合计、价税合计大写

**🆕 火车票可用字段：**
- 发票号码、开票日期、购买方名称、统一社会信用代码
- 电子客票号、车次、出发站、到达站
- 乘车日期、乘车时间、座位号、车厢号、票价、姓名

**字段选择建议：**
| 场景 | 推荐字段组合 |
|------|------------|
| 财务归档 | 开票日期 + 销售方名称 + 价税合计 |
| 报销使用 | 开票日期 + 购买方名称 + 发票号码 |
| 供应商管理 | 销售方名称 + 开票日期 + 价税合计 |
| 项目核算 | 购买方名称 + 开票日期 + 合计金额 |

**第四步：设置分隔符**
- 在"字段分隔符"输入框中输入分隔符
- 留空则字段直接连接
- 常用分隔符：
  - `_` （下划线）：推荐，兼容性好
  - `-` （短横线）：简洁
  - ` ` （空格）：可读性好但Windows文件名不推荐
  - `.` （点）：简短
  - `,` （逗号）：清晰分隔

**第五步：设置前缀和后缀（可选）**

**5.5.1 自定义前缀**
- 在所有字段前添加固定文字
- 示例：
  - `发票_` → 发票_2024年01月01日_某某公司_135.20.pdf
  - `报销单_` → 报销单_2024年01月01日_某某公司_135.20.pdf
  - `2024年_` → 2024年_01月01日_某某公司_135.20.pdf

**5.5.2 自定义后缀**
- 在所有字段后、.pdf前添加固定文字
- 示例：
  - `_已核销` → 2024年01月01日_某某公司_135.20_已核销.pdf
  - `_待报销` → 2024年01月01日_某某公司_135.20_待报销.pdf
  - `_已入账` → 2024年01月01日_某某公司_135.20_已入账.pdf

**第六步：查看预览**
- 预览标签会实时显示重命名效果
- 示例：`预览: 发票_12345678_2024年01月01日_某某公司_已核销.pdf`
- 根据预览调整设置

**第七步：选择输出方式**

**5.7.1 原地重命名（默认）**
- 不勾选"复制到新文件夹"
- 直接在原文件夹重命名
- 优点：节省空间
- 缺点：会改变原文件，建议备份

**5.7.2 复制到新文件夹**
- 勾选"复制到新文件夹"
- 点击"选择文件夹"选择输出位置
- 将重命名后的文件复制到新文件夹
- 优点：保留原文件
- 缺点：占用更多空间

**第八步：执行重命名**
1. 点击"2. 执行重命名"按钮
2. 软件开始重命名：
   - 显示进度
   - 日志显示每个文件的重命名结果
3. 完成后显示成功数量
4. 🆕 **自动检测重复发票**：再次提示是否有重复发票
5. 查看示例结果

**第九步：检查结果**
1. 打开文件夹查看重命名后的文件
2. 确认文件名符合预期
3. 如有问题，可以撤销（如果有备份）

### 5.4 字段值清理说明

软件会自动清理文件名中的非法字符：
- 删除Windows不允许的字符：`\ / : * ? " < > |`
- 删除多余空格
- 示例：
  - `C:\用户` → `C用户`
  - `公司/部门` → `公司部门`
  - `文件:说明` → `文件说明`

### 5.5 注意事项

⚠️ **重要提示：**
- **原地重命名前务必备份原文件！**
- 如果多个文件重命名后文件名相同，会自动添加序号（_1, _2...）
- 文件名不宜过长（建议不超过100字符）
- 特殊字符会被自动删除
- 如果某个字段为空，该字段不会出现在文件名中

- [ ] 已提取发票信息
- [ ] 预览效果符合预期
- [ ] 分隔符设置正确
- [ ] 前缀后缀（如有）正确
- [ ] 已备份原文件（原地重命名时）
- [ ] 输出文件夹已选择（复制模式时）
